# おかねクイズ大会

マネリテDAOが学校やイベントの「お金の授業」で使ってきたクイズを、小学生向けの4択問題集にしたものです。1回10問をランダムに出題し、1問ごとに正解と解説を表示して100点満点で採点します。ふりがな付き（ボタンで消せます）。スマホのホーム画面に追加するとアプリのように使えます（PWA）。

公開URL: https://masatopapa.github.io/okane-quiz/

- 「しょうがくせい」（既定）と「ぜんぶ」（おとな向けの問題も混ざる）の2つのレベルがあります。
- 外国の値段の問題は、ページを開いたときにネットにつながっていれば、その日の為替相場（ECB公表レート）で日本円に計算し直します。解説に計算した日付と相場を表示します。
- 税金・金利・年金などの数字は、毎週の自動チェックで最新の公表値に更新しています。それでも作った時点の数字が残ることがあります。
- 更新はネット優先のService Workerで自動配信されます（次に開いたときに新版になります）。
